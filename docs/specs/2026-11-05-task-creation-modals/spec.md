## 1. Контекст и цель

Карточка «Интерактивно» на главном экране сейчас даёт только haptic и не
выполняет никакого действия. Нужно открыть по ней полноценную форму
быстрого создания задачи, соответствующую макетам Figma: название, метки,
приоритет, срок, регулярность и автонапоминания. Форма отправляет данные в
реальный API (`POST /tasks` для разовой задачи и `POST /task-series` для
ежедневной серии).

Одновременно нужно привести шапку существующего модального окна записи
голосом к макетам: центрированный заголовок, кнопка закрытия справа и
разделитель под шапкой. Логика записи голоса не меняется.

Метки только загружаются (`GET /labels`); создание, редактирование и
удаление меток в этой итерации не выполняются.

## 2. Пользовательские сценарии

1. Пользователь нажимает «Интерактивно» на главной. Открывается нижняя
   шторка «Добавление задачи»; поле названия пустое, подставлены текущие
   дата/время пользователя, приоритет P2, автонапоминания включены с
   правилом «за 1 час».
2. Пользователь вводит название и нажимает «Добавить задачу». Для разовой
   задачи вызывается `POST /tasks`, форма закрывается, звучит success
   haptic, главный экран перезапрашивает данные.
3. Пользователь открывает «Метки», выбирает несколько существующих меток
   и нажимает «Применить». Чип меток показывает первую метку и `+ N`.
4. Пользователь открывает «Приоритет задачи», выбирает один из четырёх
   вариантов и нажимает «Применить». Чип показывает P1–P4.
5. Пользователь открывает «Дата и время задачи», выбирает дату в
   календаре, время через нативный time-picker и включает «Регулярная
   задача». Подсказка снизу плавно меняется с «Сегодня, 16:00» на
   «С 11.11.2026, ежедневно в 16:00». По «Готово» создаётся ежедневная
   серия через `POST /task-series`.
6. Пользователь открывает «Автонапоминания», выключает мастер-тумблер —
   блок настроек плавно скрывается. По «Применить» правила сохраняются в
   черновике формы.
7. Пользователь открывает запись голосом и видит новую шапку с кнопкой X;
   закрытие через X или нижнюю кнопку «Закрыть» останавливает запись и
   сбрасывает состояние.

## 3. Функциональные требования

### FR-1. Шапка модального окна записи голосом

- Шапка — отдельная строка высотой `54px`, горизонтальные и вертикальные
  отступы `15px`.
- Заголовок `Голосовое сообщение` — `17px`, Semi Bold, по центру, цвет
  `app-text`.
- Справа — кнопка закрытия X: видимая иконка `24×24`, зона нажатия не
  меньше `44×44`, `aria-label="Закрыть"`, цвет `app-text`.
- Слева — невидимый спейсер `24×24`, чтобы заголовок оставался
  центрированным.
- Под шапкой — разделитель `1px` цвета `app-stroke`.
- X и нижняя кнопка `Закрыть` вызывают один и тот же обработчик: haptic
  selection, `reset()` записи, `onOpenChange(false)`.
- Тело голосового окна сохраняет прежнее поведение и копирайт; отступы
  приводятся к макету: `15px` сверху, `24px` по бокам, `30px` снизу, gap
  `20px`, ширина контента `332px` на панели `380px`.
- Панель голосового окна остаётся высотой `380px`; нижняя кнопка
  «Закрыть» — отдельный блок `50px` с gap `10px`, радиусы `25px`.

### FR-2. Точка входа и открытие формы

- Нажатие на карточку «Интерактивно» в `QuickAccessSection` открывает
  `QuickAddSheet`.
- Одновременно открыта только одна модалка: при открытии формы голосовая
  шторка закрывается и наоборот.
- Haptic `impact("light")` на нажатие карточки сохраняется.
- Форма открывается через существующий `Modal variant="sheet"` с overlay,
  focus trap, блокировкой скролла и анимацией появления.
- Клик по overlay не закрывает форму (защита от потери черновика).
  Закрывают только X, Escape и нижняя кнопка `Закрыть`.
- В подэкранах X закрывает всю форму, кнопка «назад» (шеврон слева)
  возвращает на главный шаг формы без применения изменений подэкрана.

### FR-3. Главный шаг формы

- Шапка: заголовок `Добавление задачи`, кнопка X справа, разделитель.
- Контент:
  1. Пояснение: `Введите быструю задачу, например: Запись к стоматологу
     в четверг на 10 утра`, `15px`, `app-text-secondary`, line-height
     `1.3`.
  2. Строка `Название` (`15px`, `app-text`) и счётчик `N/120` (`15px`,
     `app-text-secondary`) по краям.
  3. Многострочное поле ввода высотой `104px`, радиус `25px`, рамка
     `1px app-stroke`, фон `app-card`, внутренние отступы `12px 15px`,
     placeholder `Запись к стоматологу завтра в 10 утра`.
  4. Горизонтально прокручиваемая строка чипов высотой `45px`, gap `10px`.
  5. Кнопка `Добавить задачу` высотой `50px`, радиус `25px`, фон
     `app-accent`, текст `15px` Semi Bold белый.
- Счётчик показывает длину введённой строки без trim, максимум `120`.
- Поле названия ограничено `maxLength=120`.
- Кнопка `Добавить задачу` активна только если `title.trim().length > 0` и
  мутация не выполняется.
- Во время отправки текст кнопки — `Добавляем...`, кнопка disabled.
- Нижняя кнопка `Закрыть` — отдельный блок `50px`, радиус `25px`, фон
  `app-card`, текст `15px` Semi Bold цвета `app-accent`.
- При ошибке создания форма остаётся открытой, черновик сохраняется,
  показывается текст ошибки над кнопкой отправки, звучит error haptic.
- При успехе: success haptic, закрытие формы, сброс черновика,
  `useRevalidator().revalidate()` и инвалидация React Query ключей
  `["tasks"]` и `["task-series"]`.

### FR-4. Чипы быстрых действий

Все чипы: высота `45px`, радиус `50`, рамка `1px app-stroke`, фон
`app-card`, текст `13px`, gap `10px`, `type="button"`, zóna нажатия не
меньше `45px`. Строка прокручивается по горизонтали без видимого
скроллбара.

1. **Дата и время.** Иконка календаря + текст + иконка повтора, если
   включена регулярность.
   - сегодня: `Сегодня, HH:mm`;
   - завтра: `Завтра, HH:mm`;
   - другая дата: `На DD.MM.YYYY, HH:mm`.
   - Чип активен (рамка и текст `app-accent`) всегда, потому что срок
     обязателен.
2. **Метки.** Иконка тега с плюсом.
   - `0` меток: только иконка, `aria-label="Выбрать метки"`;
   - `1` метка: имя метки;
   - `> 1`: `<первая метка>... + N`, где `N = selected.length - 1`;
   - имя обрезается, чтобы чип не растягивался больше `200px`;
   - иконка тега окрашена цветом первой выбранной метки.
3. **Приоритет.** Текст `P1`–`P4`.
   - `urgent_important` → `P1`;
   - `important_not_urgent` → `P2` (значение по умолчанию);
   - `urgent_not_important` → `P3`;
   - `neither` → `P4`.
4. **Напоминание.** Текст `Напоминание`. Активный стиль (`app-accent`),
   если мастер включён и включено хотя бы одно правило.

### FR-5. Подэкран «Метки»

- Шапка: кнопка «назад», заголовок `Метки`, кнопка X, разделитель.
- Метки загружаются `GET /api/v1/labels` при открытии формы (React Query,
  ключ `["labels"]`).
- Состояния:
  - загрузка: текст `Загружаем метки…` (`15px`, secondary);
  - ошибка: текст `Не удалось загрузить метки` и кнопка `Повторить`;
  - пусто: ровно `На текущий момент у вас не создано ни 1 метки`
    (`15px`, secondary, по центру);
  - успех: список строк высотой `47px` с разделителями `app-stroke`.
- Строка метки: круглый индикатор выбора, иконка тега цвета метки, имя
  метки цветом `label.color.hex`.
- Выбор мультивыборный: повторное нажатие снимает выбор. Визуально
  выбранная метка — синее кольцо с синей точкой; невыбранная — серая
  рамка.
- Внизу — кнопка `Применить` (`50px`, `app-accent`). Она сохраняет
  `label_ids` в черновик и возвращает на главный шаг.
- Метки не создаются и не редактируются.
- Дубликаты `id` удаляются; максимум `100` меток (ограничение API).
- Если метка была удалена на сервере и `POST` вернул `404`, форма
  показывает `Метки больше недоступны. Обновите список.` и инвалидирует
  `["labels"]`.

### FR-6. Подэкран «Приоритет задачи»

- Шапка: «назад», заголовок `Приоритет задачи`, X, разделитель.
- Четыре строки высотой `50px` с разделителями:
  1. `Срочные и важные` → `urgent_important`;
  2. `Важные, но не срочные` → `important_not_urgent`;
  3. `Срочные, но не важные` → `urgent_not_important`;
  4. `Не срочные и не важные` → `neither`.
- У выбранной строки слева синяя галочка `24×24`; у остальных — пустой
  спейсер.
- Кнопка `Применить` сохраняет приоритет и возвращает на главный шаг.
- По умолчанию выбран `important_not_urgent` (P2).

### FR-7. Подэкран «Дата и время задачи»

- Шапка: «назад», заголовок `Дата и время задачи`, X, разделитель.
- Календарь:
  - навигация по месяцам: шевроны `24×24` цвета `app-accent`, заголовок
    `Ноябрь 2026` (`17px` Semi Bold);
  - дни недели `ПН ВТ СР ЧТ ПТ СБ ВС` (`11px`, secondary);
  - сетка 6 недель по 7 дней, понедельник первый;
  - ячейка дня `48×36`; выбранный день — заливка `app-accent`, белый
    текст, радиус `25`;
  - дни соседних месяцев — цвет `app-stroke`, кликабельны и переключают
    месяц;
  - диапазон дат ограничен `2025-01-01 … 2100-12-31`;
  - сегодняшний день не имеет отдельной заливки, если не выбран.
- Строка времени:
  - подпись `Время` (`16px`);
  - нативное поле `<input type="time">` в pill `114×44`, радиус `12`,
    фон `app-track`, текст `17px` Semi Bold цвета `app-accent`,
    `aria-label="Время"`;
  - по нажатию открывается системный time-picker.
- Строка `Регулярная задача` (`16px`) и переключатель `48×28`.
- Подсказка снизу (`13px`, secondary, одна строка, `aria-live="polite"`):
  - регулярная задача: `С DD.MM.YYYY, ежедневно в HH:mm`;
  - разовая задача сегодня: `Сегодня, HH:mm`;
  - разовая задача на другую дату: `На DD.MM.YYYY, HH:mm`.
- При переключении регулярности подсказка плавно заменяется (см. FR-11),
  без скачка высоты панели.
- Кнопка `Готово` сохраняет дату, время и регулярность в черновик и
  возвращает на главный шаг.
- Значение по умолчанию при открытии формы — текущие локальные дата и
  время пользователя (секунды `0`) в часовом поясе `user.timezone`.

### FR-8. Подэкран «Автонапоминания»

- Шапка: «назад», заголовок `Автонапоминания`, X, разделитель.
- Значения по умолчанию:
  - мастер `Автонапоминания` — включён;
  - `До срока задачи` — включено, значение `1`, единица `Часов`;
  - `По расписанию` — выключено, интервал `Каждый день`, время `14:00`.
- Мастер-строка: `Автонапоминания` + переключатель. При выключении весь
  блок настроек плавно скрывается; при включении — плавно появляется.
- Блок `НАСТРОЙКИ` (`13px`, secondary, uppercase).
- `До срока задачи` + переключатель. Когда включено:
  - подпись `За сколько до завершения задачи напомнить` (`13px`,
    secondary);
  - поле числа `114×48` (pill, фон `app-track`, синий текст Semi Bold) и
    `SelectField` единицы (`Минут`, `Часов`, `Дней`);
  - helper: `Напоминание будет выслано в чат с Milly один раз до её
    завершения.`
  - число приводится к целому, минимум `1`; итоговые `offset_minutes`
    ограничиваются диапазоном `1…525600` (API `0…525600`).
- `По расписанию` + переключатель. Когда включено:
  - две колонки с подписями `Повторять` и `Время`;
  - `SelectField` интервала: `Каждый день` (1), `Каждые 2 дня` (2),
    `Каждые 3 дня` (3), `Каждые 4 дня` (4), `Каждую неделю` (7);
  - нативное поле времени в pill `114×48`, фон `app-track`, синий текст;
  - helper: `Напоминание по расписанию будет высылаться в чат с Milly
    каждый заданный промежуток времени.`
- Если мастер выключен, `reminders_enabled=false` и `reminders=[]`.
- Если мастер включён, но оба правила выключены, также отправляется
  `reminders_enabled=false`, `reminders=[]`.
- Если мастер включён и включено хотя бы одно правило, отправляется
  `reminders_enabled=true` и массив активных правил.
- Кнопка `Применить` сохраняет настройки в черновик и возвращает на
  главный шаг.

### FR-9. Активный select box

- Триггер: высота `49px`, радиус `25px`, фон `app-track`, текст `15px`,
  шеврон `18×18` справа.
- Popup рендерится в портал (`createPortal`), позиционируется под
  триггером по его `getBoundingClientRect()`; ширина списка `306px`,
  внешний padding `15px`, итоговая ширина `336px`, радиус `25px`, фон
  `app-card`, тень `0 12px 40px rgba(0, 0, 0, 0.25)`.
- Каждый вариант — строка `53–55px`, текст `15px`, разделитель
  `app-stroke` между строками (у последней строки нет).
- Выбранный вариант отмечен синей галочкой `24×24` справа.
- Открытие/закрытие: `opacity 0→1`, `scale 0.96→1`, `160ms ease-out`;
  `transform-origin: top`.
- Закрытие: клик вне, Escape, повторное нажатие на триггер, скролл
  страницы.
- Клавиатура: `ArrowDown`/`ArrowUp` перемещают фокус по вариантам,
  `Enter`/`Space` выбирают, `Escape` закрывает и возвращает фокус на
  триггер.
- Используется для выбора единицы времени и интервала напоминания.

### FR-10. Отправка формы и API

- Все запросы идут через `apiRequest` из `app/lib/api/client.ts`; прямых
  `fetch`/`axios` в компонентах нет.
- Метки: `GET /labels` → `{ items: LabelResponse[] }`.
- Разовая задача:
  `POST /tasks` с телом `TaskCreateInput`:
  - `title` — trim;
  - `due_at` — ISO 8601 с offset (`Z`), собранный из выбранных локальных
    даты/времени и `user.timezone`;
  - `priority`;
  - `label_ids` — без дублей;
  - `reminders_enabled`;
  - `reminders`;
  - `project_id` не передаётся.
- Регулярная задача (ползунок включён):
  `POST /task-series` с телом `SeriesCreateInput`:
  - `frequency: "daily"`;
  - `interval_days` не передаётся;
  - `time_of_day: "HH:mm:00"`;
  - `timezone: user.timezone`;
  - `starts_on: YYYY-MM-DD`;
  - `title`, `priority`, `label_ids`, `reminders_enabled`, `reminders`;
  - `project_id` и `ends_on` не передаются.
- Правила напоминаний:
  - `before_due`: `{ kind: "before_due", enabled: true,
    offset_minutes }`;
  - `scheduled`: `{ kind: "scheduled", enabled: true, interval_days,
    time_of_day: "HH:mm:00" }`;
  - порядок правил: сначала `before_due`, затем `scheduled`.
- Ошибки классифицируются в `describeQuickAddError(error)`:
  - `ApiNetworkError`/timeout → `Не удалось подключиться. Проверьте сеть и
    попробуйте ещё раз.`;
  - `ApiError` `422`/`400` → `Проверьте заполнение формы и попробуйте
    ещё раз.`;
  - `ApiError` `404` → `Метки больше недоступны. Обновите список.`;
  - `ApiError` `429` → `Слишком много запросов. Попробуйте позже.`;
  - `ApiError` `5xx` → `Сервис временно недоступен. Попробуйте ещё раз.`;
  - иначе → `Не удалось добавить задачу. Попробуйте ещё раз.`.
- `401` обрабатывает существующий auth-aware клиент; форма не показывает
  отдельный экран.
- Успешное создание серии не гарантирует, что экземпляр появится сегодня:
  это определяет backend. UI не пытается угадать сгенерированные задачи.
- После успеха:
  - `queryClient.invalidateQueries({ queryKey: ["tasks"] })`;
  - `queryClient.invalidateQueries({ queryKey: ["task-series"] })`;
  - `useRevalidator().revalidate()`;
  - success haptic, закрытие формы, сброс черновика.

### FR-11. Анимация переключения подэкранов

- Главная форма и подэкраны живут в одной панели; при переключении
  подэкран меняется внутри панели, а не открывается новая модалка.
- Контейнер шагов:
  - `motion.div` с `layout`;
  - `AnimatePresence mode="popLayout"`;
  - у контейнера `position: relative`, `overflow: hidden`;
  - layout-переход: spring stiffness `400`, damping `36`, mass `0.9`.
- Направление перехода:
  - вперёд (form → labels/priority/due/reminders): новый шаг входит
    `x: 40 → 0`, `opacity: 0 → 1`, `scale: 0.98 → 1`; старый уходит
    `x: 0 → -40`, `opacity: 1 → 0`;
  - назад: зеркально.
- Переход `x` — spring stiffness `420`, damping `38`, mass `0.8`;
  `opacity` — `180ms ease-out`.
- Высота панели плавно уменьшается/увеличивается за счёт layout-проекции
  Motion; не используется ручной `setState` на каждый кадр.
- Подсказка в календаре меняется через `AnimatePresence mode="wait"`:
  `y: 6 → 0`, `opacity: 0 → 1`, `180ms`.
- Скрытие настроек напоминаний: `height: auto → 0` + `opacity`, `220ms
  ease-out`, `overflow: hidden`.
- Переключатели: позиция бегунка — spring stiffness `500`, damping `32`;
  цвет трека — `180ms`.
- Все анимации — только `transform`, `opacity` и layout-проекция Motion;
  layout-свойства не анимируются вручную.
- При `prefers-reduced-motion: reduce` Motion отключает transform/layout-
  анимации; остаются opacity-переходы. Смысл интерфейса не теряется.
- Целевой бюджет — 60 fps на среднем мобильном устройстве.

| `scheduledEnabled` | `false` |
| `scheduledIntervalDays` | `1` |
| `scheduledTime` | `"14:00"` |

### 4.3. Валидация

- Zod-схема — единственный источник правил; react-hook-form использует её
  через собственный resolver без новой зависимости.
- `title`: trim, `1…120`.
- `dueDate`: `YYYY-MM-DD`, диапазон `2025-01-01 … 2100-12-31`.
- `dueTime`: `HH:mm`.
- `priority`: один из четырёх enum.
- `labelIds`: целые `> 0`, без дублей, максимум `100`.
- `beforeDueAmount`: целое `>= 1`; итоговый `offset_minutes` не больше
  `525600`.
- `scheduledIntervalDays`: одно из `1, 2, 3, 4, 7`.
- `scheduledTime`: `HH:mm`.
- Кнопка отправки дополнительно disabled, если `title.trim()` пуст или
  мутация выполняется.

### 4.4. Часовой пояс и даты

- `getZonedNow(now, timeZone)` возвращает локальные `year/month/day/hour/
  minute` через `Intl.DateTimeFormat.formatToParts`.
- `zonedDateTimeToIso(date, time, timeZone)` собирает UTC-момент двумя
  проходами: предполагает UTC, вычисляет offset зоны для этого момента,
  корректирует и повторяет расчёт offset. Это корректно обрабатывает DST.
- `formatDueChip` и `formatDueHint` используют локальную дату пользователя
  и правила из FR-4/FR-7.
- `getMonthGrid(year, month)` возвращает 42 ячейки, начиная с
  понедельника; `addDays(date, n)` работает по календарным дням без
  зависимости от DST.
- Запрещено использовать `new Date("YYYY-MM-DD")` без времени для
  сравнения локальных дней: такая строка парсится как UTC и может дать
  сдвиг на день.

### 4.5. React Query

- Метки: `useQuery({ queryKey: ["labels"], queryFn: ({ signal }) =>
  fetchLabels(signal) })`; запрос стартует при открытии формы.
- Создание: `useMutation` в хуке `useCreateQuickTask`; сама мутация
  выбирает `createTask` или `createSeries` по `isRecurring`.
- Инвалидация после успеха: `["tasks"]`, `["task-series"]`.
- Ошибки не перехватываются глобально; форма показывает локальный текст.

## 5. Визуальная спецификация

### 5.1. Общая геометрия шторки

- Ширина панели — ширина viewport минус `15px` с каждой стороны, но не
  больше `max-w-md` (`448px`); на ширине `412px` панель `382px`.
- Радиус панели `25px`, фон `app-card`, внешние отступы safe-area:
  `max(15px, var(--app-inset-left/right))`,
  `max(15px, var(--app-inset-bottom))`.
- Шапка `54px`, padding `15px`, заголовок `17px` Semi Bold по центру,
  разделитель `1px app-stroke`.
- Кнопки назад/закрытия: видимая иконка `24×24`, зона нажатия `44×44`,
  цвет `app-text`.
- Нижняя кнопка «Закрыть» — отдельный блок `50px`, gap `10px` от панели,
  радиус `25px`, фон `app-card`, текст `15px` Semi Bold `app-accent`.
- Панель формы имеет auto-height; максимальная высота —
  `calc(var(--tg-viewport-stable-height, 100dvh) - var(--app-inset-top) -
  var(--app-inset-bottom) - 90px)`. Тело скроллится, шапка остаётся на
  месте.
- На ширинах `320 / 412 / 448px` нет горизонтального скролла страницы;
  чипы прокручиваются только внутри своей строки.

### 5.2. Главный шаг

- Внутренние отступы тела `15px`; gap между смысловыми блоками `20px`.
- Пояснение — `15px`, line-height `1.3`, `app-text-secondary`.
- Строка названия — `15px`, `app-text` / `app-text-secondary`.
- Поле ввода — `350×104`, радиус `25`, рамка `1px app-stroke`, padding
  `12px 15px`, `15px`.
- Чипы — `45px`, gap `10px`, радиус `50`, рамка `1px app-stroke`.
- Кнопка создания — `350×50`, радиус `25`, `app-accent`, белый текст
  `15px` Semi Bold.

### 5.3. Подэкраны

- Метки: панель auto-height; строки `47px`; имя метки окрашено в
  `label.color.hex`; кнопка `Применить` внизу.
- Приоритет: строки `50px`; выбранная строка с галочкой; кнопка
  `Применить`.
- Дата и время: календарь `350px` шириной; ячейка `48×36`; время
  `114×44`; переключатель `48×28`; подсказка `13px`; кнопка `Готово`.
- Автонапоминания: мастер-строка `59px`; блок настроек с gap `15px`;
  поля числа/времени `114×48`; селекты `215×49`; helper-тексты `13px`;
  кнопка `Применить`.
- Select popup — по FR-9.

### 5.4. Иконки

- Новые монохромные иконки добавляются в `app/assets/icons/` и
  используются через `AssetIcon` с `bg-current`: календарь, часы, повтор,
  тег, тег с плюсом, шеврон вниз/влево/вправо, галочка, флажок.
- Иконки декоративные: `aria-hidden="true"`; доступное имя задаётся на
  кнопке/поле.
- Цвет иконки метки — `label.color.hex`.

### 5.5. Состояния

- Disabled-кнопка: `opacity 40%`, `cursor-not-allowed`.
- Нажатие: `active:opacity-70`; haptic — только через `useTelegram()`.
- Ошибка формы: текст `13px` цвета `app-destructive` над кнопкой
  отправки, `role="alert"`.
- Загрузка меток: нейтральный текст без спиннера (спиннер не требуется
  макетом).
- Пустой список меток: точный текст из FR-5, по центру.

## 6. Темы и Telegram

- Используются только токены `app-*`; `dark:`-классы не добавляются.
- Светлая и тёмная палитры уже заданы в `app/app.css`:
  `app-bg`, `app-card`, `app-text`, `app-text-secondary`, `app-stroke`,
  `app-accent`, `app-track`, `app-destructive`.
- Figma-цвета маппятся на токены: `#ffffff → app-card`,
  `#303033 → app-text`, `#7a7d83 → app-text-secondary`,
  `#e9e9ee → app-stroke`, `#007aff → app-accent`,
  `#f2f2f7 → app-track`.
- Safe-area применяет `BottomSheet`; компоненты формы не добавляют
  фиксированных отступов под чёлку/навигацию.
- Для максимальной высоты используется `--tg-viewport-stable-height`, не
  `viewportHeight`.
- Haptics: открытие/закрытие, применение подэкрана, переключение
  переключателей, успех/ошибка создания — через `useTelegram().haptics`.
- Нативный header Telegram не дублируется.
- При открытии клавиатуры панель остаётся в пределах стабильного
  viewport; при переходе между шагами активный элемент blur-ится, чтобы
  клавиатура не перекрывала подэкран.

## 7. Доступность

- `role="dialog"`, `aria-modal="true"`, `aria-labelledby` на заголовок
  шага, `aria-describedby` на пояснение главного шага.
- Focus trap и возврат фокуса обеспечивает существующий `Modal`.
- Начальный фокус — на контейнере диалога, не на текстовом поле, чтобы
  клавиатура не открывалась автоматически.
- Кнопки X и «назад» имеют `aria-label` (`Закрыть`, `Назад`).
- Переключатели — `role="switch"`, `aria-checked`, доступное имя из
  подписи.
- Select — `aria-haspopup="listbox"`, `aria-expanded`,
  `role="listbox"`/`role="option"`, `aria-selected`; Escape возвращает
  фокус на триггер.
- Календарь — `role="grid"`, строки `role="row"`, ячейки `role="gridcell"`,
  выбранная дата `aria-selected="true"`, сегодня — `aria-current="date"`,
  месяц озвучивается заголовком.
- Время — нативный `<input type="time">` с `aria-label="Время"`.
- Чипы — кнопки с `aria-haspopup="dialog"`; после применения подэкрана
  фокус возвращается на чип, который его открыл.
- Ошибка отправки — `role="alert"`; подсказка срока — `aria-live="polite"`.
- Минимальная зона нажатия — `44×44` для кнопок шапки и переключателей.
- При reduced motion остаются текстовые статусы и opacity-переходы.

## 8. Нефункциональные требования

- SSR включён; форма не рендерится в SSR-ответе, пока `open === false`.
- Нет доступа к `window`, `document`, `navigator` на верхнем уровне
  модулей — только в эффектах и обработчиках.
- Портал создаётся только после монтирования на клиенте.
- Новые зависимости не добавляются: `motion@14`, `react-hook-form`,
  `zod` уже установлены; импорт Motion — только из `motion/react`.
- TypeScript strict, без `any`; типы — через `import type`.
- Файлы — kebab-case, компоненты — PascalCase, алиас `~/`.
- Все таймеры, listeners, ResizeObserver/IntersectionObserver (если
  появятся) очищаются при закрытии/unmount.
- Секреты, access/refresh-токены и `initData` не логируются и не
  сохраняются в браузерных/Telegram-хранилищах.
- Тесты — Vitest, `app/**/*.test.ts`; линтера в проекте нет.
- Целевая производительность — 60 fps на среднем мобильном устройстве.
- Форма не ломается при пустом списке меток, ошибке сети, повторной
  отправке и закрытии во время мутации (мутация абортится по signal при
  закрытии).

## 11. Принятые решения

- SDD-документы: `docs/specs/2026-11-05-task-creation-modals/`.
- Одна спецификация покрывает шапку голосового окна и форму быстрого
  создания: это связанные изменения модальных окон создания задачи.
- Ползунок регулярности создаёт только ежедневную серию (`daily`).
- Метки — мультивыбор; создание меток не входит в задачу.
- Приоритет по умолчанию — `important_not_urgent` (P2), чип P1–P4.
- Дата/время по умолчанию — текущие локальные дата/время пользователя.
- Время выбирается нативным `<input type="time">`.
- Автонапоминания включены по умолчанию; «До срока» — 1 час; «По
  расписанию» выключено.
- «Применить» в подэкране сохраняет изменения и возвращает на главный шаг;
  X закрывает всю форму, «назад» отбрасывает изменения шага.
- Клик по overlay не закрывает форму; Escape закрывает.
- Пустой список меток использует точную формулировку заказчика.
- Подсказка для разовой задачи на другую дату использует формат
  `На DD.MM.YYYY, HH:mm`; для сегодня — `Сегодня, HH:mm`.
- Новые зависимости не добавляются; zod-resolver для react-hook-form
  реализуется локально.
