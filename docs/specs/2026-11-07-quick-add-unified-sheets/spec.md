# Milly — единый сценарий шторок деталей быстрого создания (SDD Specification)

**Статус:** approved (2026-11-07)
**Дата:** 2026-11-07
**Область:** `frontend/`
**Связанные спецификации:**
`docs/specs/2026-11-05-task-creation-modals/spec.md`,
`docs/specs/2026-11-06-inline-quick-add/spec.md`,
`docs/specs/2026-11-06-quick-add-zustand/spec.md`,
`docs/specs/2026-11-06-quick-add-project/spec.md`

## 1. Контекст и цель

Шторка «Дата и время задачи» уже переведена на полноэкранный сценарий:
разворачивается на всю доступную высоту, показывает крестик закрытия в
шапке, закрывается свайпом вниз и не имеет нижней кнопки «Закрыть».
Остальные шторки деталей быстрого создания («Метки», «Проект»,
«Приоритет задачи», «Автонапоминания») остались компактными: крестика
нет, используется нижняя кнопка «Закрыть», свайп не работает.

Цель итерации — привести все пять шторок деталей к единому сценарию
«Дата и время задачи», не меняя содержимое шагов, данные и семантику
применения/отбрасывания изменений.

## 2. Пользовательские сценарии

1. Пользователь нажимает любой чип деталей. Шторка открывается на всю
   доступную высоту с заголовком, крестиком в шапке и без нижней кнопки
   «Закрыть».
2. Контент шага короче панели. Кнопка «Применить»/«Готово» прижата к
   низу панели с отступом `15px`.
3. Контент шага длиннее панели (список меток/проектов, настройки
   напоминаний). Контент прокручивается; свайп вниз начинается только с
   шапки, чтобы не мешать прокрутке; кнопка действия находится в конце
   контента.
4. Пользователь закрывает шторку крестиком, свайпом, оверлеем или
   Escape. Неприменённые изменения шага отбрасываются, фокус
   возвращается на чип — как раньше.
5. Пользователь нажимает «Применить»/«Готово». Значения коммитятся,
   шторка закрывается, фокус возвращается на чип — как раньше.

## 3. Функциональные требования

### FR-1. Оболочка шторки

- `QuickAddDetailSheet` для любого непустого шага передаёт в
  `BottomSheet`:
  - `expanded`;
  - `showCloseButton`;
  - `swipeToClose`;
  - `panelAnimateLayout`;
  - `bodyClassName="p-[15px]"`.
- Проп `footer` не передаётся: нижней кнопки «Закрыть» больше нет.
- `BottomSheetAction` остаётся экспортированным для голосовой шторки; из
  `QuickAddDetailSheet` он не импортируется.
- Шапка — общий `SheetHeader`: заголовок шага по центру, крестик справа,
  разделитель снизу. Кнопки «назад» нет.
- Expanded-панель занимает высоту от
  `max(15px, var(--app-inset-top))` сверху до
  `var(--app-inset-bottom)` снизу, с отступами `15px` по бокам.

### FR-2. Раскладка шагов

Каждый из компонентов `LabelsStep`, `ProjectStep`, `PriorityStep`,
`RemindersStep`:

- корневой контейнер — `flex flex-1 flex-col`;
- `BottomSheetPrimaryAction` обёрнут в
  `<div className="mt-auto pt-[15px]">`;
- собственный `className="mt-[15px]"` у кнопки удаляется.

`DueStep` уже соответствует FR-2 и не меняется.

### FR-3. Применение и закрытие

- «Применить»/«Готово» коммитит значения шага в черновик, даёт haptic
  `selection`, закрывает шторку и возвращает фокус на чип.
- Закрытие без применения (крестик, свайп, оверлей, Escape)
  отбрасывает неприменённые изменения шага и возвращает фокус на чип.
- Ранее применённые значения формы сохраняются.
- Свайп вниз закрывает шторку при смещении больше `100px` или скорости
  больше `600px/s` — существующее поведение `BottomSheet`.

### FR-4. Доступность

- Крестик имеет доступное имя `Закрыть` (значение по умолчанию
  `SheetHeader`).
- Focus trap, начальный фокус, возврат фокуса и закрытие по Escape
  обеспечиваются существующими `Modal`/`BottomSheet`.
- Роли `radiogroup`/`radio`/`checkbox`, `aria-checked` и подписи шагов не
  меняются.

### FR-5. Тесты

- `quick-add-detail-sheet.test.ts` проверяет для каждого шага
  (`labels`, `project`, `priority`, `due`, `reminders`):
  `expanded=true`, `swipeToClose=true`, `showCloseButton=true`,
  `footer=null`.
- Тесты `labels-step`, `project-step`, `priority-step`,
  `reminders-step` дополнительно проверяют наличие классов
  `flex flex-1 flex-col` и `mt-auto pt-[15px]`.
- Существующие проверки содержимого, состояний, disabled и обработки
  ошибок сохраняются.

### FR-6. Документация

- `AGENTS.md`: правило шапки/закрытия/разворота шторок деталей
  обновляется на единый сценарий для всех шагов.
- В `2026-11-06-inline-quick-add/spec.md` (FR-3) и
  `2026-11-06-quick-add-project/spec.md` (FR-2) добавляется пометка, что
  поведение шапки и закрытия заменено этой спецификацией.

## 4. Визуальная спецификация

| Элемент | Значение |
|---|---|
| Панель | `rounded-[25px]`, `bg-app-card` |
| Верхний отступ expanded | `max(15px, var(--app-inset-top))` |
| Нижний отступ expanded | `var(--app-inset-bottom)` |
| Боковые отступы | `max(15px, var(--app-inset-left/right))` |
| Padding тела | `15px` |
| Шапка | `54px`, разделитель `1px app-stroke`, X `24×24` |
| Кнопка действия | `50px`, радиус `25px`, `app-accent`, белый текст |
| Отступ кнопки от контента | `15px` |

- Только токены `app-*`; `dark:`-классы и хардкод цветов Telegram не
  добавляются.
- Ширины `320 / 412 / 448px`, light/dark и safe-area не ломаются.

## 5. Нефункциональные требования

- Новые зависимости не добавляются.
- SSR включён; шторки открываются только после `AuthGate`.
- TypeScript strict, без `any`; типы — через `import type`.
- Файлы — `kebab-case`, компоненты — `PascalCase`, алиас `~/`.
- Тесты — Vitest, `app/**/*.test.ts`.
- Линтера в проекте нет; `npm run lint` не добавлять.

## 6. Вне scope

- Изменение содержимого шагов, высот строк, отступов списков и логики
  выбора.
- Изменение данных, React Query, API и payload.
- Голосовая шторка (`VoiceRecorderSheet`) и её нижняя кнопка «Закрыть».
- Изменение `BottomSheet`/`Modal`/`SheetHeader` API.
- Анимации переходов между шагами.
- E2E/браузерные тесты.

## 7. Критерии приёмки

- [ ] Любой чип деталей открывает развёрнутую шторку с крестиком в
      шапке и без нижней кнопки «Закрыть».
- [ ] Свайп вниз закрывает шторку; при прокручиваемом контенте свайп
      начинается только с шапки.
- [ ] «Применить»/«Готово» прижата к низу при коротком контенте и
      находится в конце контента при длинном.
- [ ] Закрытие без применения отбрасывает изменения шага; «Применить»
      коммитит их.
- [ ] Голосовая шторка сохраняет нижнюю кнопку «Закрыть».
- [ ] `npm test`, `npm run typecheck`, `npm run build` проходят.
- [ ] Вручную проверены light/dark, ширины `320 / 412 / 448px`,
      safe-area, клавиатура и свайп.

## 8. Принятые решения

- Единый сценарий — это текущее поведение шага «Дата и время»:
  `expanded`, `showCloseButton`, `swipeToClose`, без footer.
- Кнопка действия остаётся внутри тела шага, а не в footer.
- Содержимое шагов и их тесты поведения не переделываются.
- Старые спецификации не переписываются целиком; конфликтующие пункты
  помечаются ссылкой на эту спецификацию.

## 9. Связь с существующими спецификациями

- `2026-11-05-task-creation-modals`: общие требования к шапке
  (`назад`/X) и нижним кнопкам применяются с учётом этой итерации;
  содержимое шагов сохраняется.
- `2026-11-06-inline-quick-add`: FR-3 в части отсутствия X и нижней
  «Закрыть» заменяется этой спецификацией.
- `2026-11-06-quick-add-project`: FR-2 в части шапки и нижней
  «Закрыть» заменяется этой спецификацией.
- `2026-11-06-quick-add-zustand`: семантика `stepDraft`, `applyStep` и
  отбрасывания изменений не меняется.
