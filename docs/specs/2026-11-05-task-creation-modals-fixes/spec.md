## 1. Контекст и цель

Базовая итерация быстрого создания задачи реализована, но визуальная
сверка с Figma и ручная проверка в Telegram выявили дефекты:

1. вёрстка модальных окон расходится с фреймами по отступам, вложенным
   отступам, составу чипов и размерам pill-полей;
2. у активного текстового поля синяя рамка фокуса видна сверху, но
   обрезается по бокам;
3. в календаре можно выбрать дату раньше сегодняшней;
4. настройки «До срока задачи» и «По расписанию» появляются без
   анимации, хотя мастер-блок «Автонапоминания» анимируется;
5. в шапке модалок есть крестик X, хотя есть нижняя кнопка «Закрыть»;
   крестик нужно убрать, сохранив центрирование заголовка;
6. при открытии клавиатуры нижняя шторка уходит под неё, футер
   «Закрыть» и часть формы становятся недоступны.

Цель итерации — устранить эти дефекты, привести быстрые модалки к
Figma и сделать шторку устойчивой к клавиатуре на iOS и Android, не
меняя API, модель формы, payload и бизнес-логику создания задачи.

## 2. Пользовательские сценарии

1. Пользователь открывает «Добавление задачи», ставит курсор в поле
   названия. Синяя рамка фокуса видна со всех четырёх сторон; при
   открытии клавиатуры шторка поднимается над ней, заголовок, поле и
   нижняя кнопка остаются доступны.
2. Пользователь открывает «Дата и время задачи». Даты раньше
   сегодняшнего дня в часовом поясе пользователя недоступны; кнопка
   «Предыдущий месяц» disabled, пока показан текущий месяц.
3. Пользователь включает «Автонапоминания». Блок настроек плавно
   раскрывается. Внутри него включение «До срока задачи» и «По
   расписанию» так же плавно раскрывает соответствующие поля, а
   выключение — плавно скрывает.
4. Пользователь открывает любой подэкран. Слева есть «назад», справа
   крестика нет, заголовок остаётся по центру. Закрытие — нижней
   кнопкой «Закрыть» или Escape.
5. Пользователь открывает форму на устройстве шириной 412px, 448px и
   больше. Ширина панели — не более 448px, на 412px — 382px;
   горизонтального скролла страницы нет. Чипы прокручиваются только
   внутри своей строки.
6. Пользователь заполняет форму и видит структуру по Figma: подпись
   «Название» и счётчик с внутренним отступом 15px, чип приоритета без
   иконки флажка, чип напоминания без иконки часов, pill-поля
   напоминаний с радиусом 28px и текстом 15px.

## 3. Текущее состояние и причины дефектов

- **Рамка фокуса.** Текстовое поле использует
  `focus-visible:outline-2 outline-offset-2`. Outline выходит за границы
  поля на 4px, а обёртка шага имеет `overflow-hidden`
  (`quick-add-sheet.tsx`), поэтому боковые сегменты обрезаются.
- **Календарь.** `DueStep` передаёт `minDate={MIN_DATE}`, где
  `MIN_DATE = "2025-01-01"`. Сегодняшняя дата вычисляется, но
  используется только для `aria-current` и подсказки.
- **Анимация напоминаний.** Мастер-блок обёрнут в `AnimatePresence` +
  `motion.div` с `height: auto → 0`. Вложенные блоки «До срока» и «По
  расписанию» — обычные условные фрагменты без `AnimatePresence`.
- **Крестик.** `SheetHeader` всегда рендерит `onClose`, если он передан;
  `BottomSheet` по умолчанию передаёт `onOpenChange(false)`.
- **Клавиатура.** В проекте нет `visualViewport`, нет пересчёта
  положения шторки и нет `interactive-widget` в meta viewport. Шторка
  позиционируется `fixed bottom-0` и использует
  `--tg-viewport-stable-height`, который не следует за клавиатурой.
- **Вёрстка.** Сверка с Figma показала: подпись/счётчик без бокового
  отступа 15px; gap между подписью и полем 10px вместо 5px; внутренний
  gap чипов 10px вместо 2–5px; чипы приоритета и напоминания содержат
  лишние иконки; pill-поля напоминаний имеют радиус 24px и текст 17px
  вместо 28px и 15px; helper-тексты без дополнительного отступа 15px;
  навигация календаря занимает 44px по высоте вместо 24px.

## 4. Функциональные требования

### FR-1. Шапка без крестика

- `SheetHeader` больше не принимает `onClose`/`closeLabel` и не
  рендерит кнопку X. Компонент `CloseIcon` удаляется.
- `BottomSheet` больше не принимает `showCloseButton` и не передаёт
  `onClose` в `SheetHeader`.
- Слева в шапке:
  - на подэкранах — кнопка «назад» (шеврон `24×24`, зона нажатия
    `44×44`, `aria-label="Назад"`);
  - на главном шаге — невидимый спейсер `24×24`.
- Заголовок остаётся абсолютно центрированным: `left-1/2`,
  `-translate-x-1/2`, `17px` Semi Bold, `app-text`, одна строка.
- Справа спейсер не требуется: заголовок не участвует в flex-потоке.
- Высота шапки `54px`, горизонтальные отступы `15px`, разделитель
  `1px app-stroke`.
- Закрытие формы: нижняя кнопка «Закрыть», Escape, успешная отправка.
  Клик по overlay по-прежнему не закрывает форму.
- Изменение применяется к форме быстрого создания и к голосовой шторке:
  в обеих остаётся нижняя кнопка «Закрыть».

### FR-2. Геометрия шторки и главного шага

- Ширина панели: `min(viewport - 2 × max(15px, safe-area), 448px)`.
  На ширине `412px` панель `382px`; на ширинах больше `478px` — не
  больше `448px`. Текущее ограничение `max-w-md` на обёртке с padding
  15px даёт 418px и должно быть исправлено.
- Радиус панели — `25px` (main-фрейм `54:7044`); подэкраны в Figma
  нарисованы с радиусом `24px`, но используется одна панель, поэтому
  радиус остаётся `25px` для всех шагов.
- Тело главного шага: padding `15px`, gap между смысловыми блоками
  `20px`.
- Строка «Название» / счётчик:
  - горизонтальные отступы `15px` внутри поля шириной `350px`;
  - подпись `15px app-text`, счётчик `15px app-text-secondary`;
  - gap до текстового поля `5px` (сейчас 10px).
- Текстовое поле: `350–352×104` (на viewport `412px` — `352px`),
  радиус `25px`, рамка `1px app-stroke`, фон `app-card`, padding
  `12px 15px`, текст/placeholder `15px`.
- Кнопка «Добавить задачу»: `50px`, радиус `25px`, `app-accent`,
  белый текст `15px` Semi Bold. Disabled — `opacity 40%`,
  `cursor-not-allowed`.
- Нижняя кнопка «Закрыть»: отдельный блок `50px` с gap `10px` от
  панели, радиус `25px`, фон `app-card`, текст `15px` Semi Bold
  `app-accent`.
- На ширинах `320 / 412 / 448px` нет горизонтального скролла страницы.

### FR-3. Фокус активного поля и элементов формы

- Все фокусируемые элементы внутри прокручиваемого тела шторки
  используют **внутреннее** кольцо фокуса:
  `focus-visible:outline-2 focus-visible:-outline-offset-2
  focus-visible:outline-app-accent` либо эквивалентный `ring-inset`.
- Это относится к: текстовому полю, primary-кнопкам, чипам, Switch,
  TimeInput, SelectField (триггер и опции), календарю (навигация и дни),
  строкам меток и приоритета, кнопке «Повторить».
- Внешний `outline-offset-2` внутри шага не используется: он обрезается
  `overflow-hidden` обёртки шага.
- Рамка фокуса не вызывает сдвига layout и не меняет размеры элемента.
- В обычном состоянии поле сохраняет рамку `1px app-stroke`; при фокусе
  синяя рамка видна со всех четырёх сторон.
- Контраст кольца к фону — не ниже 3:1; цвет — `app-accent`.
- Фокус на контейнере диалога и focus trap не меняются.

### FR-4. Чипы быстрых действий

- Порядок: дата и время, метки, приоритет, напоминание.
- Контейнер: gap `10px`, горизонтальный скролл, скрытый скроллбар;
  высота чипов `45px`, радиус `50px`, рамка `1px`, фон `app-card`,
  текст `13px`.
- **Дата и время.** Иконка календаря `24×24`, текст, иконка повтора при
  регулярности. Внутренний gap `2px`, padding `10px`. Чип всегда
  активен (`border-app-accent`, `text-app-accent`).
- **Метки.** Внутренний gap `5px`, padding `10px`.
  - `0` меток: только `tag-plus`, квадратный чип `45×45`;
  - `1` метка: имя;
  - `> 1`: `<первая>... + N`;
  - имя обрезается так, чтобы чип не превышал `200px`;
  - иконка окрашена цветом первой метки.
- **Приоритет.** Только текст `P1–P4`, без иконки флажка. Квадратный чип
  `45×45`, текст по центру, `padding 10px`, рамка `app-stroke`, текст
  `app-text`.
- **Напоминание.** Только текст `Напоминание`, без иконки часов.
  Padding `10px`, ширина по контенту. Активный стиль — если мастер
  включён и включено хотя бы одно правило.
- Иконки `flag.svg` и `clock.svg` в строке чипов больше не
  используются; сами файлы не удаляются.
- В рабочем дереве уже есть несохранённые изменения
  `app/assets/icons/calendar.svg`, `tag.svg`, `tag-plus.svg` из Figma.
  Их нельзя откатывать. Если требуется правка, форма иконки
  сохраняется; SVG остаётся пригодным для `AssetIcon` (mask).

### FR-5. Календарь: запрет дат в прошлом

- Минимальная дата выбора — сегодняшняя дата в часовом поясе
  `user.timezone` (`formatZonedToday(now, timeZone)`).
- Максимальная дата — `2100-12-31`; ограничение API `2025-01-01 …
  2100-12-31` не меняется.
- Дни раньше сегодняшнего:
  - `disabled`, `aria-disabled` не требуется отдельно, `opacity-40`,
    `cursor-not-allowed`;
  - не вызывают `onSelect`;
  - не могут быть выбраны с клавиатуры.
- Кнопка «Предыдущий месяц» disabled, если показанный месяц не позже
  месяца минимальной даты.
- «Сегодня» остаётся выбираемой датой и не имеет отдельной заливки,
  если не выбрана.
- При открытии `DueStep` переданная дата, которая оказалась раньше
  сегодняшней (например, из устаревшего состояния), заменяется на
  сегодняшнюю до отображения.
- Ограничение действует и для регулярной задачи: `starts_on` не может
  быть раньше сегодня.
- Ограничение по времени суток (нельзя выбрать время раньше текущего
  для сегодняшнего дня) **в эту итерацию не входит**.
- Zod-схема и payload не меняются; ограничение — UI-уровня.

### FR-6. Анимация вложенных настроек напоминаний

- В `app/components/ui/` добавляется переиспользуемый примитив
  `Collapsible`:
  - `open: boolean`, `children`, опциональные `className` и
    `contentClassName`;
  - `AnimatePresence initial={false}`;
  - `motion.div` с `height: 0 → auto`, `opacity: 0 → 1`,
    `overflow: hidden`;
  - `transition: { duration: 0.22, ease: "easeOut" }`;
  - при закрытии — обратная анимация `height: auto → 0`,
    `opacity: 1 → 0`.
- `RemindersStep` использует `Collapsible` для трёх уровней:
  1. мастер-блок «Автонапоминания» → весь блок «НАСТРОЙКИ»;
  2. «До срока задачи» → подпись, число + единица, helper;
  3. «По расписанию» → интервал + время, helper.
- Вложенные блоки анимируются независимо; выключение мастера плавно
  сворачивает весь блок, включая уже открытые вложенные настройки.
- Состояние вложенных переключателей при выключении мастера не
  сбрасывается; при повторном включении они открываются в прежнем
  состоянии.
- Высота панели анимируется существующей layout-проекцией Motion;
  ручной `setState` на каждый кадр не используется.
- При `prefers-reduced-motion: reduce` высотная анимация отключается
  (контент появляется без движения), opacity-переходы остаются.
- Анимация не должна ломать нормализацию скрытого времени и disabled
  «Применить».

### FR-7. Отступы и размеры шага «Автонапоминания»

- Тело шага: padding `15px`.
- Мастер-строка: `59px` (padding `15px` сверху/снизу), подпись `16px`,
  Switch `48×28`.
- Блок «НАСТРОЙКИ»: `13px`, uppercase, `app-text-secondary`;
  padding-top `15px` от мастер-строки.
- Группы «До срока задачи» и «По расписанию»: gap `15px` между
  группами.
- Внутри группы:
  - строка переключателя визуально `28px`; зона нажатия Switch остаётся
    `44×48` за счёт отрицательных вертикальных отступов, как у кнопок
    шапки;
  - gap от строки до полей `10px`;
  - горизонтальный gap между pill и select `15px`;
  - поля и helper: gap `5px`.
- Pill числа «за сколько»: `114×48`, радиус `28px`, фон `app-track`,
  текст `15px` Semi Bold, `app-accent`, по центру.
- Pill времени в расписании: `114×48`, радиус `28px`, фон `app-track`,
  текст `15px` Semi Bold, `app-accent`, по центру. Для этого
  `TimeInput` получает вариант `compact`; вариант по умолчанию
  (шаг «Дата и время») остаётся `114×44`, радиус `12px`, текст `17px`.
- Select единицы и интервала: `215×49`, радиус `25px`, фон `app-track`,
  текст `15px`.
- Helper-тексты: `13px`, line-height `1.4`,
  `app-text-secondary`, дополнительный горизонтальный отступ `15px`
  внутри контента шириной `352px`.
- Кнопка «Применить»: `50px`, радиус `25px`, `app-accent`, текст
  `15px` Semi Bold, белый; disabled — `opacity 40%`.
- «Укажите время» и disabled «Применить» при невалидном времени
  сохраняются.

### FR-8. Клавиатура и visual viewport

- В `<meta name="viewport">` добавляется
  `interactive-widget=resizes-content` (для Android/WebView, где это
  поддерживается). На iOS атрибут игнорируется, поэтому основная
  компенсация — через `visualViewport`.
- Добавляется хук `useKeyboardViewport(enabled: boolean)` (или
  эквивалент в `app/hooks/`), который при открытой шторке:
  - подписывается на `window.visualViewport.resize` и
    `window.visualViewport.scroll`;
  - дополнительно слушает `window.resize` и `orientationchange`;
  - вычисляет `keyboardInset = max(0, window.innerHeight -
    (visualViewport.height + visualViewport.offsetTop))`;
  - отдаёт `keyboardInset` и `viewportHeight =
    visualViewport.height`;
  - коалесцирует обновления через `requestAnimationFrame`;
  - удаляет listeners и отменяет rAF при закрытии/unmount.
- `BottomSheet` при `keyboardInset > 0`:
  - сдвигает контейнер вверх: `bottom = keyboardInset` (без CSS
    transition, чтобы следовать за клавиатурой без лага);
  - ограничивает панель по `visualViewport.height`, а не по
    `--tg-viewport-stable-height`;
  - не добавляет нижний safe-area повторно: нижний padding `15px`
    вместо `max(15px, --app-inset-bottom)`;
  - сохраняет footer «Закрыть» видимым над клавиатурой;
  - тело шторки остаётся `overflow-y-auto`, шапка закреплена.
- При `keyboardInset === 0` поведение прежнее: `bottom: 0`,
  `maxHeight` от `--tg-viewport-stable-height`, нижний safe-area
  `max(15px, var(--app-inset-bottom))`.
- После обновления метрик, если `document.activeElement` находится
  внутри тела шторки, выполняется
  `scrollIntoView({ block: "nearest", inline: "nearest" })` для
  активного элемента (в следующем кадре), чтобы поле не оказалось под
  клавиатурой.
- Fallback: если `visualViewport` недоступен, используется текущее
  поведение; ошибок и падений нет.
- `viewportHeight` Telegram не используется для позиционирования
  нижних панелей; `--tg-viewport-stable-height` остаётся базой без
  клавиатуры.
- Переходы между шагами по-прежнему вызывают `blur()` активного
  элемента, чтобы скрыть клавиатуру.

### FR-9. Доступность и сохраняемое поведение

- `role="dialog"`, `aria-modal="true"`, `aria-labelledby` на заголовок
  шага, `aria-describedby` на пояснение главного шага — без изменений.
- Focus trap и возврат фокуса обеспечивает `Modal`.
- Начальный фокус — на контейнере диалога, не на текстовом поле.
- Кнопка «назад» имеет `aria-label="Назад"`; нижняя «Закрыть» —
  доступное имя из текста.
- Календарь: `role="grid"`, `role="row"`, `role="gridcell"`,
  `aria-selected`, `aria-current="date"`; disabled-дни имеют нативный
  `disabled`.
- Switch: `role="switch"`, `aria-checked`, `aria-label`.
- Select: `aria-haspopup="listbox"`, `aria-expanded`,
  `role="listbox"`/`role="option"`, `aria-selected`; Escape возвращает
  фокус на триггер.
- После применения подэкрана фокус возвращается на чип, который его
  открыл. После «назад» фокус остаётся на кнопке «назад»/возвращается
  в диалог по текущему поведению.
- Минимальная зона нажатия `44×44` для кнопок шапки, Switch и
  навигации календаря.
- При reduced motion смысл интерфейса не теряется.

## 5. Данные и состояние

- API, `QuickTaskDraft`, zod-схема, payload, React Query-ключи и
  обработка ошибок не меняются.
- `minDate` календаря вычисляется из `now` и `user.timezone` при
  открытии `DueStep`; отдельного состояния не создаётся.
- `useKeyboardViewport` хранит только транзиентные метрики viewport.
- `Collapsible` — stateless-компонент; анимацией управляет Motion.
- Никаких новых записей в localStorage/sessionStorage/Telegram
  Storage.

## 7. Telegram, safe-area и клавиатура

- Без клавиатуры: `bottom: 0`, `maxHeight` от
  `--tg-viewport-stable-height` (fallback `100dvh`), нижний safe-area
  `max(15px, var(--app-inset-bottom))`.
- С клавиатурой: `bottom = keyboardInset`, `maxHeight` от
  `visualViewport.height`, нижний padding `15px`.
- `viewportHeight` Telegram не используется для нижней панели.
- `interactive-widget=resizes-content` добавляется в meta viewport.
- Haptics: открытие/закрытие, применение подэкрана, переключение
  Switch, успех/ошибка — без изменений.
- Нативный header Telegram не дублируется.
- Ручная проверка обязательна на iOS и Android в Telegram: клавиатура,
  safe-area, светлая/тёмная тема, fullscreen, поворот экрана.

## 8. Нефункциональные требования

- SSR включён; форма не рендерится в SSR-ответе при `open === false`.
- Нет доступа к `window`, `document`, `visualViewport` на верхнем
  уровне модулей — только в эффектах и обработчиках.
- Все listeners, rAF и таймеры очищаются при закрытии/unmount.
- Новые зависимости не добавляются: `motion`, `react-hook-form`,
  `zod`, React Query уже установлены.
- TypeScript strict, без `any`; типы — через `import type`.
- Файлы — kebab-case, компоненты — PascalCase, алиас `~/`.
- `cn()` не выполняет tailwind-merge: конфликтующие классы не
  наслаивать, а задавать через варианты/пропсы.
- Тесты — Vitest, `app/**/*.test.ts`; компонентные тесты — статический
  SSR (`renderToStaticMarkup`), чистые helper-функции — обычные unit
  tests.
- Целевая производительность — 60 fps; обновления viewport только по
  rAF.
- Секреты, токены и `initData` не логируются и не сохраняются.
- Форма не ломается при пустом списке меток, ошибке сети, повторной
  отправке и закрытии во время мутации.
- В рабочем дереве есть несохранённые изменения трёх SVG-иконок; их
  нельзя откатывать или коммитить без явного решения.

## 10. Критерии приёмки

- [ ] В шапке нет крестика X; заголовок центрирован; на подэкранах
      слева есть «назад»; закрытие — нижней кнопкой и Escape.
- [ ] При фокусе на текстовом поле синяя рамка видна со всех сторон;
      другие контролы в шторке не обрезают фокус.
- [ ] Даты раньше сегодняшней недоступны; «Предыдущий месяц» disabled
      на текущем месяце; сегодня выбирается; регулярная серия тоже не
      стартует в прошлом.
- [ ] Включение/выключение мастера, «До срока» и «По расписанию»
      анимируется одинаково плавно (220ms ease-out).
- [ ] При открытой клавиатуре шторка, заголовок, поле ввода и кнопка
      «Закрыть» остаются видимыми; тело скроллится; после закрытия
      клавиатуры шторка возвращается вниз без скачка.
- [ ] Ширина панели на 412px — 382px, на широких экранах — не больше
      448px; горизонтального скролла страницы нет.
- [ ] Главный шаг соответствует Figma: отступы подписи/счётчика, gap
      5px, чипы без лишних иконок, кнопки 50px.
- [ ] Автонапоминания: pill-поля 114×48 радиус 28px с текстом 15px,
      select 215×49, helper с отступом 15px.
- [ ] Light/dark темы и safe-area не ломаются; используются только
      `app-*` токены.
- [ ] `npm test`, `npm run typecheck`, `npm run build` проходят.
- [ ] SSR-ответ главной не содержит открытой формы; `curl -i
      http://localhost:3000/does-not-exist` отдаёт 404.
- [ ] В Telegram вручную проверены клавиатура, тема, safe-area,
      haptics и нативный time-picker на iOS и Android.
- [ ] В рабочем дереве не откачены и не перезаписаны несохранённые
      Figma-иконки.

## 11. Принятые решения

- SDD-документы: `docs/specs/2026-11-05-task-creation-modals-fixes/`.
- Крестик удаляется из общей шапки, а не скрывается только для
  quick-add: нижняя «Закрыть» есть в обеих шторках.
- Ограничение календаря — UI-уровня; схема и API остаются прежними.
- Фокус — внутреннее кольцо, чтобы не зависеть от `overflow-hidden`.
- Для анимации вложенных настроек вводится общий `Collapsible`; мастер
  и вложенные блоки используют один transition 220ms ease-out.
- Клавиатура компенсируется через `visualViewport`, а не через
  `viewportHeight`; `interactive-widget=resizes-content` —
  дополнительный слой для Android.
- Радиус общей панели остаётся 25px, несмотря на 24px у некоторых
  подэкранов Figma: панель одна и не должна «прыгать» между шагами.
- Чипы приоритета и напоминания приводятся к Figma: только текст.
- Ширина панели исправляется на уровне обёртки, а не через глобальный
  `max-w-md`.
- Несохранённые изменения иконок из Figma сохраняются.
- Выбор времени в прошлом для сегодняшнего дня не ограничивается.
