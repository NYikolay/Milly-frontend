# Экран «Автоматические напоминания» (`/tasks/:id/reminders`)

- `/tasks/:id/reminders` («Автоматические напоминания») использует
  `GET /tasks/{id}` с детальным ключом и `PATCH /tasks/{id}`; строка
  «Напоминание» на `/tasks/:id` открывает эту страницу.
  Мастер-переключатель «Автонапоминания» и два правила («До срока задачи»,
  «По расписанию») сохраняются автоматически без кнопки «Готово»;
  мутации сериализуются через `scope: "task-reminders"`, success-haptic
  не вызывается. Выключение мастера отправляет только
  `reminders_enabled: false` и сохраняет правила на сервере; выключение
  последнего включённого правила автоматически выключает мастер и очищает
  `reminders: []`.
  Ошибка PATCH показывается над контентом с текстом «Не удалось
  сохранить напоминания. Попробуйте ещё раз.» и кнопкой «Повторить»,
  повторяющей последний payload; значения формы не сбрасываются.
  Если момент `before_due` уже прошёл (`next_run_at` такого правила
  backend не создаёт), значение остаётся в форме, под карточкой
  показывается «Напоминание уже прошло», а PATCH с этим правилом не
  отправляется; выключение мастера и правил сохраняется как обычно.

## Связанные общие правила

- Проверки — в `docs/agents/qa.md` (раздел «`/tasks/:id/reminders`»).
