# Экран «Поиск задач» (`/tasks/search`)

## Данные и фильтры

- `/tasks/search` использует `GET /tasks` с серверными `date`, `project_ids`,
  `priorities`, `status`, `recurrence`, `q` (`limit=100`), а также
  `GET /projects?limit=100` и `GET /labels`; данные загружаются React Query
  после `AuthGate`. Дата по умолчанию — сегодня; `date=null` означает
  сегодня и не считается активным фильтром, выбранная дата меняет день
  списка и заголовок. Фильтр проекта — мультивыбор реальных проектов
  (`project_ids`); строки «Без проекта» в фильтре нет, а «Сбросить»
  показывается только при непустом выборе. Метки не входят в серверный
  ключ поиска и не уходят в API: `filterTasksForDisplay` применяет их на
  клиенте по AND среди загруженных `limit=100`, там же повторно
  применяется статус. Поиск серверный по
  `title`/`description`, выполняется при каждом изменении поля (`q.trim()`,
  пустой `q` не отправляется); предыдущие результаты остаются до ответа
  нового запроса. Завершение задачи оптимистично обновляет кэш поиска,
  инвалидирует `["tasks"]` и `["projects"]`; при активном статус-фильтре
  строка скрывается/возвращается сразу. Пагинация не реализована
  (`limit=100`, `next_cursor` игнорируется).
- Фильтры `/tasks/search` живут в `search-filters-reducer.ts`
  (`step`, `draft`, `applied`, `openedDirectly`): «Применить»/«Готово»
  под-шага, открытого из «Все фильтры», обновляют только черновик и
  возвращают в «Все фильтры»; под-шаг, открытый напрямую с чипа панели,
  применяет патч к `applied` и закрывает шторку; back отбрасывает
  неприменённые правки шага; крестик, оверлей, Escape и свайп вниз
  закрывают шторку и отбрасывают весь черновик; общий «Применить»
  применяет черновик и закрывает шторку; «Сбросить фильтры» сразу
  очищает применённое, закрывает шторку и возвращает сегодня. Чипы
  «По приоритету»/«Проект»/«Периодичность» и иконка календаря открывают
  свои под-шаги, бейдж «Все фильтры» считает активные группы (0…6).
  В фильтре регулярности только «Ежедневные»/«Разовые»: периодические
  серии отдельной опцией не фильтруются. Dev-preview `?state=filter`
  показывает бейдж «1» и активный чип «Проект» только в dev-режиме, не
  меняя данные.

## UI

- Экран «Поиск задач» повторяет каркас `/tasks`: сегменты «Сегодня/Поиск задач/
  Проекты», заголовок «Поиск задач», поисковое поле `SearchField`
  с `variant="stroke"`, горизонтальная панель фильтров и карточка результатов
  на `TodayTaskRow`. Заголовок и подзаголовок показываются всегда; заголовок
  списка — `Задачи на DD.MM.YYYY (N)`, включая `(0)`. Только токены `app-*`;
  ширины `320 / 412 / 448px`, light/dark и safe-area не ломаются.
- Шторки фильтров `/tasks/search` — один `BottomSheet` (`expanded`,
  `showCloseButton`, `swipeToClose`, `panelAnimateLayout`, body
  `p-[15px]`) с общим `SheetHeader`; переход между шагами — смена
  содержимого без вложенных `Modal`. Только токены `app-*` (light/dark
  через `data-app-theme`, без `dark:` и хардкода цветов). Во всех
  шагах-списках строки `50px` без зазоров, разделитель `app-stroke` под
  каждой строкой, кроме последней. «Все фильтры»: иконка `18px`, текст
  `15px/1.3`, chevron `24px`, активная группа `app-accent`;
  «Применить» — `50px`, радиус `25px`, `bg-app-accent`;
  «Сбросить фильтры» — отдельная панель `footer`,
  `text-app-destructive`. Под-шаги: круг выбора `20×20` с точкой `15×15`
  `bg-app-accent`; поиск проектов/меток — существующий `SearchField`,
  списки — с отступом `mt-[15px]` от поиска; клавиатуру обрабатывает
  `BottomSheet` (тело прокручивается, панель не меняет размер). Метки —
  `tag-raw.svg` `18px` и текст цветом `label.color.hex`; проекты —
  `ProjectIconBadge` `28×28`; дата — существующий `Calendar` и подпись
  `13px/1.4` `app-text-secondary`. Чипы и бейдж — существующие
  `OptionChip` и бейдж `14×14`.
