# Быстрое создание задачи

- Быстрое создание задачи начинается с inline-композера на главном экране
  (`QuickAddComposer`): поле, чипы и кнопки живут в постоянной секции, а шаги
  деталей (метки, проект, приоритет, дата и время, напоминания) открываются
  модальной `QuickAddDetailSheet`. Метки и проекты читаются через `GET /labels`
  и `GET /projects?limit=100` (read-only); чип проекта идёт после «Метки» и
  показывает «Без проекта» или выбранный проект. Создание — `POST /tasks` для
  разовой задачи и `POST /task-series` для ежедневной серии; `project_id`
  уходит в оба payload (`null` для «Без проекта»), а `["projects"]`
  инвалидируется после создания и перезапрашивается при `404` или архивном
  `400` с выбранным проектом. Обязательный `AuthUser.timezone`
  используется для расчёта `due_at` и поля `timezone` серии. Шторки
  «Метки» и «Проект» имеют поле «Поиск» с фильтрацией по названию;
  проекты показываются круглым бейджем `28×28` с белой иконкой,
  «Без проекта» — `no-project.svg` на `bg-app-track`, в «Метках» —
  `tag-raw.svg`; основная кнопка обеих шторок — «Готово».
- Шапка шторки — общий `SheetHeader` внутри `BottomSheet`: back, заголовок,
  разделитель и опциональный крестик закрытия (`showCloseButton`). Все шторки
  деталей быстрого создания («Метки», «Проект», «Приоритет», «Дата и время»,
  «Автонапоминания») разворачиваются через `BottomSheet expanded`, показывают
  крестик в шапке, закрываются оверлеем, Escape, крестиком и свайпом вниз;
  нижней кнопки «Закрыть» у них нет. При прокручиваемом контенте свайп
  начинается только с шапки, чтобы не ломать скролл; кнопка
  «Применить»/«Готово» прижата к низу панели через `mt-auto`, а при длинном
  контенте находится в конце прокрутки. Закрытие без «Применить»/«Готово»
  отбрасывает неприменённые изменения шага, ранее применённые значения формы
  сохраняются. Панель шторки деталей использует `panelAnimateLayout`;
  переходов между шагами больше нет.
  `MotionConfig reducedMotion="user"` в `AppProviders` отключает
  transform-анимации при reduced motion.

## Связанные общие правила

- Круглый бейдж проекта, чип меток, строки списков и поиск — в `docs/agents/ui.md`.
- Zustand-состояние композера — в `docs/agents/data-and-state.md`.
- Проверки — в `docs/agents/qa.md` (раздел «Быстрое создание»).
