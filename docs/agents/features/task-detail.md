# Экран «Детали задачи» (`/tasks/:id`)

- `/tasks/:id` использует `GET /tasks/{id}`, `POST /tasks/{id}/complete`,
  `POST /tasks/{id}/uncomplete`, `DELETE /tasks/{id}`. Данные загружаются
  React Query после `AuthGate`; ключ — `["tasks","detail",id]`; проекты и
  метки читаются через существующие `["projects"]`/`["labels"]`. Строки
  `/tasks` и `/tasks/search` открывают детали, чекбокс остаётся отдельным.
  Завершение оптимистично; удаление — через модалку, после успеха или
  `404` — назад по истории (fallback `/tasks`). Детальный ключ обязан
  оставаться под `["tasks"]`.
- `/tasks/:id` строка «Срок» открывает `TaskDueSheet`; PATCH `/tasks/{id}`
  отправляет `due_at` только при смене момента и `recurrence` только при
  смене переключателя; `periodic` сохраняет интервал; выключение
  регулярности отправляет `one_off`; успех инвалидирует `["tasks"]`,
  `["task-series"]`, `["projects"]` и детальный ключ; при PATCH `404`
  детальный ключ инвалидируется дополнительно; ошибка показывается
  в шторке.

## UI

- Экран `/tasks/:id` («Детали задачи») по спецификации
  `docs/specs/2026-11-08-task-detail/spec.md`: только токены `app-*`; карточка
  свойств `app-card`, радиус `25px`, `p-[15px]`, пять строк по `47px` без
  промежутков; ведущие иконки `calendar.svg`, `bell.svg` (новая),
  `flag.svg`, `tag.svg`, `folder.svg`; разделитель `app-stroke` под каждой
  строкой, кроме последней; шевроны декоративные. Строки карточки свойств
  неинтерактивны, кроме «Срок» и «Напоминание»: «Срок» открывает шторку
  «Дата и время задачи» (BottomSheet, `showCloseButton`, свайп, только
  `app-*`, 320/412/448 px, safe-area), «Напоминание» — страницу
  `/tasks/:id/reminders`.
  Значение проекта — текст без `ProjectIconBadge`. Под карточкой —
  `Создано DD.MM.YYYY, HH:mm` и две кнопки `50px` («Отметить
  выполненной»/«Сделать активной» и «Удалить задачу»). Удаление — через
  существующий `Modal` (`variant="sheet"`): две панели `app-card`, для
  каскадной задачи серии предупреждение, фокус возвращается на кнопку.
  Строка задачи в `/tasks` и `/tasks/search` открывает детали отдельной
  кнопкой; чекбокс завершает задачу и детали не открывает.
